### Etapa: consolidação e validação Windows

- Ambiente de estudo com sessões, player e navegação ajustada a janelas largas.
- Materiais, notas, referências com destaque de excertos e pesquisa externa opcional.
- Aula guiada com etapas persistidas. Aula booleana experimental desligada por padrão; laboratório separado do aplicativo.
- README reorganizado, relatórios em uma pasta comum e compilação local separada da instalação pessoal.

### Validação e limites

O [QA da PR #10](https://github.com/Dinox75/Ritmo/blob/2a319a30f853a3068ae51264f127db67f816e56a/docs/qa/qa-windows-pr10.md) registra 102 testes, verificações em 390/1366/1920 px, áudio Realtek, sessões, materiais e fluxos booleanos. A compilação validada foi feita durante a PR, sem instalar sobre os dados pessoais; os detalhes de procedência estão no relatório.

Esta entrada é retrospectiva e inclui apenas **Source code (zip/tar.gz)**. Não distribui o executável de QA. A etapa seguinte acrescentou proteções na API local e no motor; não use esta revisão histórica como base de instalação pessoal.
